# LandLens AI

Responsive React + Tailwind property research dashboard for three Waleska, Georgia vacant lots, with nearby reported home sales, maps, calculators, comparisons, notes, and due diligence checklists.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this GitHub repository into Vercel. Framework: Vite; build: `npm run build`; output: `dist`. No environment variables are required.

## Important limitations

- All property and nearby home-sale figures are preliminary listing/aggregator reports, not independently deed-verified.
- Terrain is NOT measured. Do not treat the word 'level' as a verified elevation study.
- Notes and saved properties use browser localStorage and do NOT sync across devices. Export JSON to back up or transfer changes.
- No live data feed, automated AI research, or backend is connected.
- Site is a research tool, not an appraisal or guarantee of buildability.
